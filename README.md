
# Cisco Network Topology Project

For my university networking course, I designed and configured a complex Cisco Packet Tracer network integrating multiple routers, switches, servers, and wireless devices.  
The topology was divided into several subnets, each serving specific functions such as DHCP, DNS, and Web services to simulate a realistic enterprise environment.

## Key Implementations
- Designed a hierarchical topology ensuring logical segmentation and scalability.  
- Performed subnetting on the given IP range to optimize address usage.  
- Configured **DHCP** for automatic IP assignment and **static IPs** for core infrastructure.  
- Implemented **RIP** for dynamic routing and static routes for backbone connectivity.  
- Verified full inter-network communication using ping and traceroute diagnostics.  
- Set up **Web**, **DNS**, and **DHCP** servers accessible across all subnets.  
- Integrated **wireless routers and access points** for mobile device connectivity.  
- Applied **NAT** to enable internal hosts to access external networks efficiently.
